# Sample Prompts for tailor_resume Skill

Below are examples of how to prompt the coding assistant to execute the `tailor_resume` skill.

---

### Example 1: Direct Job Description Paste (Recommended)
Use this when you have the full text of the job description.

```text
Please tailor my resumes for a new role. Here is the job description: 

[Paste Job Description text here]

Keep the styling completely unchanged and name the output directory google.
```

---

### Example 2: By Company and Role Name
Use this when you want to target a general role profile at a specific company.

```text
I want to apply for a Senior MERN Stack Developer position at Netflix. Please read my template resumes (new.html and v2.html) and tailor the content to fit this profile. Do not modify the CSS or UI styling, and place them in a separate directory named netflix.
```

---

### Example 3: Step-by-Step Flow
Use this if you want the agent to guide you through the process.

```text
I need to tailor my resumes for a job opening. Please trigger the tailor_resume skill and ask me for the job details.
```
